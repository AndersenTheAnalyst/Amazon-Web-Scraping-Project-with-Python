# Amazon Web Scraping Project with Python

## 📌 Project Overview

This project demonstrates how to use Python and Jupyter Notebook to scrape product information from Amazon. The project focuses on extracting relevant details from an Amazon product page and organizing the collected information for further use and analysis.

The product used for this project is a **Data Systems Business Analyst T-Shirt** listed on Amazon.

## 🎯 Project Objectives

- Extract product information from an Amazon webpage using Python.
- Retrieve relevant product details from the page.
- Organize the extracted data for further analysis.
- Demonstrate practical web scraping techniques using Python.

## 🛠️ Tools and Technologies

- **Python** — Web scraping and data processing.
- **Jupyter Notebook** — Writing and executing Python code interactively.
- **BeautifulSoup** — Parsing HTML content and extracting information.
- **Requests** — Sending HTTP requests to retrieve webpage content.
- **Pandas** — Organizing and managing extracted data, where applicable.

## 🌐 Data Source

The data was sourced from the following Amazon product page:

[Data Systems Business Analyst T-Shirt — Amazon](https://www.amazon.com/Data-Systems-Business-Analyst-T-Shirt/dp/B0B8Q8XWRH/)

## ⚙️ Project Workflow

### 1. Accessing the Webpage

Used Python to send a request to the Amazon product page and retrieve its HTML content, subject to the website's access restrictions.

### 2. Parsing HTML Content

Used BeautifulSoup to parse the webpage's HTML structure and locate relevant product information.

### 3. Extracting Product Information

Extracted the available product details from the webpage using Python. The specific fields depend on the HTML elements targeted in the notebook and the content accessible at the time of scraping.

### 4. Organizing the Data

Prepared the extracted information for easier viewing and potential further analysis.

This project demonstrates the practical application of Python for collecting information from webpages. It provides hands-on experience with web scraping techniques and shows how online product information can be extracted and prepared for further analysis.
